    Install as an app on your phone
    1. Open this page once in Chrome on the phone (it is saved for offline use).
    2. Chrome menu ⋮ → Add to Home screen / Install app.
    3. Open SereniSuit BT from the icon and tap Connect via Bluetooth.
    4. No need to join the suit's Wi-Fi — Bluetooth is enough.
