This folder is what GitHub Pages serves: the SereniSuit Bluetooth dashboard.

Phase 2 version (25 Nov 2026): live heart rate plus the on-chip stress model
(P(stress), calm/stressed, calibration, calming vibration, motor tests, WESAD
replay demo), skin conductance and movement. It talks to the Phase 2 firmware
(phase2/firmware). With the older Demo 1 firmware it still works - the Phase 2
cards simply stay hidden.

The Demo 1 version of the app is kept in demo1/bluetooth-app/.
